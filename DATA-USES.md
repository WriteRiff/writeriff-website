# Data uses: WriteRiff website (writeriff.com)

Every kind of data the website collects or sends. Update the row in the same change that adds, changes or removes a data flow (shared rule, 2026-11-18). Feeds the privacy policy (`site/_shared/privacy-content.html`, copied into each version's `privacy/` page).

Status 2026-11-20: the site is live at writeriff.com (GitHub Pages, repo WriteRiff/writeriff-website). The form tables are live on the dev Supabase project (app repo migration `supabase/migrations/202611200501_website_forms_dev.sql`).

| Data | Where it's collected | Where it's stored | Outside service that receives it | Why | How long it's kept | Linked to the person? |
|---|---|---|---|---|---|---|
| Beta sign-up: email (required), name and "what do you write" (optional), page signed up on, date/time | Beta form (home page and `beta/`) | Supabase table `beta_signups` (dev project `rnehrjdaruejuueztngc`) | Supabase (database host). Later, the email service used to send beta emails | To email the person about the WriteRiff beta | Until the beta ends, or sooner on request | Yes (email address) |
| News opt-in (`marketing_opt_in`): the beta form has one unticked box that must be ticked to join, covering beta emails plus news, special offers and new features, so website sign-ups are saved with `true`. The contact form has no opt-in. | Beta form | Same row as the sign-up | Supabase. Later, the email service used for news | To send WriteRiff news, special offers and new-feature emails to people who ticked the box | Until the person unsubscribes | Yes (email address) |
| Unsubscribe request: email address, date/time | `unsubscribe/` page (linked in every footer) | Supabase table `email_unsubscribes` | Supabase. The email service also handles the unsubscribe link in each email | To stop all WriteRiff news emails to that address, immediately (also turns news off on the beta list, contact rows and any app account with that email) | Kept so we never email that address news again | Yes (email address) |
| Contact message: name, email, topic, message, date/time | Contact form (`contact/`) | Supabase table `contact_messages` | Supabase | To read and answer questions and suggestions | Until answered | Yes (email address) |
| Intro "already seen" flag (`wr-intro-seen`) | Every page (opening animation) | The visitor's own browser (localStorage); never sent anywhere | None | So the opening animation plays only once per visitor | Until the visitor clears their browser data | No |
| Cloudflare Web Analytics: page views and visits (page address, referrer, browser and device type, country, page load timing) | Every website page except `account-callback/` (small script from static.cloudflareinsights.com) | Cloudflare (aggregated counts in the Beckman Studios Cloudflare account) | Cloudflare | To count visits and see which pages people read | Cloudflare's own retention for Web Analytics | No: no cookies or browser storage, no fingerprinting, no cross-site tracking; Cloudflare's servers see the IP address to deliver the script |
| Standard web server logs (IP address, browser, page requested) | Every request | Hosting provider (GitHub Pages) | GitHub | Security and keeping the site working (we don't use these) | GitHub's own retention | Not by us |
| Account pages (`account-callback/`, `delete-account/`) | Links in WriteRiff app emails | Nothing stored by the website; the callback page talks directly to Supabase Auth to confirm an email or set a new password | Supabase Auth | Part of the app's account system (covered by the app's own DATA-USES.md) | n/a | (app account) |

Not used: cookies, advertising or tracking scripts, third-party fonts or embeds. The only outside script is Cloudflare Web Analytics (cookieless, row above), described in the privacy policy's website section.
